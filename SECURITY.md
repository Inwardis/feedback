# Security Policy

**Please do not report security vulnerabilities as public issues.**

Use [GitHub's private security advisory form](https://github.com/inwardis/feedback/security/advisories/new)
for this repository — only maintainers can see reports submitted there, and we will respond
there. Include the product version (Admin → System, or `/actuator/info`) and reproduction
steps if you can.

Inwardis runs on-premise on your own infrastructure; a vulnerability report never requires
sharing your data with us. We aim to acknowledge reports quickly and will credit reporters
in release notes unless you prefer otherwise.
